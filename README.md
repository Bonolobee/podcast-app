# 🎧 Podcast App

A responsive podcast application built with React, Vite and JavaScript as part of my Software Development studies at CodeSpace Academy.

The application provides an interactive podcast browsing and listening experience, with features designed to make discovering shows and managing favourite episodes easier.

## 🚀 Live Demo

[**Explore the Podcast App**](https://podcast-project-rose.vercel.app)

## 🛠️ Tech Stack

* **React** — building reusable UI components
* **JavaScript (ES6+)** — application logic and interactivity
* **Vite** — development and build tooling
* **HTML5** — semantic page structure
* **CSS3** — styling and responsive layouts
* **localStorage** — persisting user preferences and saved data

## ✨ Features

* 🎙️ Browse podcast shows and episode information
* 🔍 Search, sort and filter podcast previews
* 📚 View show details and navigate between seasons
* 🔊 Global audio player with playback controls
* ❤️ Save favourite episodes
* 🎠 Recommended shows carousel
* 🌗 Light and dark theme options
* 📱 Responsive interface for different screen sizes
